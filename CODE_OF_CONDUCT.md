# Code of Conduct

## Our pledge

We want this project to be a place where people can learn, experiment, and collaborate without
harassment or hostility.

## Expected behavior

- Be respectful and constructive.
- Assume good faith; critique ideas, not people.
- Respect privacy: do not publish other people's account names, IP addresses, logs, or data.
- Respect copyright: do not post game assets, client files, data tables, or installation
  packages.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Doxxing or sharing private information without consent.
- Piracy, paid redistribution of game content, or solicitation for paid server operation.
- Posting credentials, tokens, or exploit details in public issues.

## Enforcement

Maintainers may edit, remove, or reject contributions and comments that violate this policy,
and may block repeat offenders. Reports can be sent through the repository's private security
reporting channel or by contacting the maintainer on GitHub.

This code of conduct applies to repository spaces (issues, pull requests, discussions) and to
public interactions where someone represents the project.
